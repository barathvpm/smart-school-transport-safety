**Theme:** Governance & Civic Technology

## 1. Project Overview

The Smart School Transport Safety System is a proposed ESP32- and
BLE-based solution to improve school transport monitoring and
communication of selected safety events.

The system is intended to support drivers, parents, and school
authorities through configurable monitoring and alert mechanisms.

## 2. Problem Statement

School transport may face overcrowding, limited monitoring, and
delays in communicating safety incidents. This project explores
an affordable technology-assisted approach to improve awareness
and communication of selected transport safety conditions.

## 3. Objectives

- Explore BLE-based transport monitoring.
- Process configured safety events using an ESP32.
- Provide alerts through the communication method implemented.
- Evaluate system reliability using controlled test cases.
