
# Project Media

This directory contains demonstration material for the Smart School Transport Safety and Monitoring System.

## Recommended Contents

- Prototype photographs.
- Hardware setup photographs.
- Architecture or circuit diagrams.
- Screenshots of serial output.
- Demonstration video, if available.

## Evidence Guidelines

1. Use photographs of the actual prototype.
2. Label simulated screenshots and generated examples clearly.
3. Do not include passwords, API keys, children's personal information, or private transport details.
4. Use descriptive filenames.
5. Confirm that any media included from other sources is properly licensed or permitted.

## Demonstration Video

If a demonstration video is available, include its filename and explain what it demonstrates.

Suggested demonstration sequence:

1. Introduce the project and its purpose.
2. Show the ESP32 and BLE beacon hardware.
3. Demonstrate beacon detection.
4. Demonstrate a missing-beacon condition, if implemented.
5. Show the resulting serial output or alert, if implemented.
6. Explain the test results and current limitations.

Do not claim that an event or alert works unless it has been demonstrated and verified.
